# Jarvis

![Designed by NFroze · Built by Jarvis](https://img.shields.io/badge/Designed_by_NFroze-Built_by_Jarvis-C0C0C8?style=for-the-badge)

AI build system. Designed by [Noah Frost](https://noahfrost.co.uk).

OpenClaw agent running on a dedicated Mac with its own AWS credentials, GitHub account, and CLI access to Claude Code. Receives a webapp brief, generates hero art from a custom LoRA, animates it into a cinemagraph, writes a full build spec, dispatches Claude Code, and delivers a live deployed webapp — end to end, one shot, no manual intervention.

Every project below was built through this pipeline. Brief → hero → animation → spec → build → deploy. What you see is what came out the other end.
